*01.2)What Is The NetBeans?
------------------------------
NetBeans Is One Of The Text Editor (IDE) That Used By Different Developers To Write Your Own Java Computer Programming Codes , And Finally Is Mainly Used To Compile , Or Execute Your Own Java Computer Programming Codes To Show The Result Of Your Own JAVA Computer Programming Codes...

*01.3)What Is The JDK?
----------------------------
JDK Refers To The Java Development Kite , It Is Mainly Used To Compile , Or Execute Your Own Java Computer Programming Codes To Show The Result (Output) Of Your Own Java Computer Programming Codes... , And It Also Contains JVM...

-----------------------------------------------------------------------------------------------
*01.4)What Is The JVM?
-----------------------------
JVM Refers To Java Virtual Machine , It Is Existing Inside JDK...

-----------------------------------------------------------------------------------------------
*01.5)What Is The JRE?
-----------------------------
JRE Refers To Java Runtime Environment , It Is Mainly Used To Run , Or Execute Your Own Java Computer Programming Codes...
